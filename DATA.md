# Data & models (not committed)

This repo contains **code only**. The datasets and generated outputs were removed to keep it lightweight.

To reproduce:
- **AutoFish** dataset: https://huggingface.co/datasets/vapaau/autofish → place under `baseline/data/autofish/`
- **MegaDescriptor-L-384** weights are downloaded automatically from Hugging Face on first run.
- Salmon re-ID data: see `baseline_salmon/download_salmon_reid.py`.

Generated analysis outputs and logs are regenerated by running the scripts.
